This is the follow-up to [Java Summer 2026](/projects/java-summer-2026/). That project took me through the first half of Liang's book and then got parked. This one picks Java back up with a different source: Tim Buchalka's "Java Masterclass" on Udemy, around 135 hours of video that I'm working through one section at a time.

The goal is threefold: go deeper on every concept I already saw over the summer, learn the ones I never reached, and understand Java from the roots instead of just well enough to pass an exercise.

## Progress

The course has 45 sections, but sections 28 to 45 are the older Java 11 version of the same material plus archived videos and extras. I'm tracking the 27 sections of the current syllabus, so the bar reaches 100% when the actual course is done.
