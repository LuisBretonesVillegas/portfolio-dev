# Fonts

Self-hosted copies of DM Sans, Playfair Display and JetBrains Mono, downloaded
from Google Fonts as woff2 (latin and latin-ext subsets, variable weight ranges).
They are registered with the Astro Fonts API in `astro.config.mjs`.

All three are licensed under the SIL Open Font License 1.1:
https://openfontlicense.org
